## 一、RL 系列（淘天-一面-2 Q1-Q5，重点）★

### Q1. GRPO 与 PPO 的核心区别（淘天-一面-2 Q1）

| 维度 | PPO | GRPO（DeepSeekMath 提出，R1 默认） |
|---|---|---|
| 优势估计 | GAE：需要 **value network**（critic）$\hat A_t = \delta_t + \gamma\lambda\delta_{t+1}+...$ | **组内相对优势**：同一 prompt 采 G 条回答，$A_i = \frac{r_i - \mathrm{mean}(\mathbf r)}{\mathrm{std}(\mathbf r)}$ |
| baseline | 学习到的 $V_\phi(s)$ | 组均值（蒙特卡洛、无偏） |
| KL 约束 | shaping 进 reward：$r_t \leftarrow r_t - \beta\log\frac{\pi_\theta}{\pi_{ref}}$ | **直接进 loss**：$-\beta\cdot D_{KL}(\pi_\theta\|\pi_{ref})$，k3 估计 |
| 显存/工程 | 训 critic（另一套同量级模型）+ GSE 调参 | 省 critic（约一半训练显存）、无 critic-policy 失配问题 |
| 适用 | 稠密奖励、滚动策略与评估策略同源 | LLM 的 outcome reward（答案对/错）天然组可比 |

一句话：**GRPO = PPO 的 actor 侧 − critic + 组内 baseline + loss-KL**。它成立的前提是 LLM RL 的奖励是序列级 0/1（同组样本同题可比），而游戏/机器人连续控制里 critic 仍难替代。实现见 `grpo.py::group_relative_advantage / grpo_loss`。

### Q2. PPO Clip 的具体作用（淘天-一面-2 Q2）

目标 $L = \mathbb E[\min(r_t A_t,\ \mathrm{clip}(r_t, 1\text{-}\epsilon, 1\text{+}\epsilon)A_t)]$，$r_t = \pi_\theta/\pi_{\theta_{old}}$：

- **限制单步更新幅度**：好动作（A>0）概率推过 1+ε 后目标不再增长（梯度截断），坏动作（A<0）压过 1-ε 后也不再继续压——防止一步把策略推崩，是 TRPO 信任域的**一阶近似**（省掉二阶 KL 约束与共轭梯度）。
- **保留 pessimistic bound**：取 min 使目标 ≤ 未截断值——更新"过度自信"时目标先被砍掉，容忍欠更新不容过更新。
- **样本复用的前提**：clip 让同一批 rollout 数据能跑多个 epoch minibatch 更新而策略偏离采样分布不失控（配合 early stop：KL 超阈值即弃批）。

性质测试见 `grpo.py` + `test_ppo_clip_blocks_overshoot`（r 超界后梯度精确为 0）。

### Q3. 重要性采样还有哪些用途？与 KL 约束更新的区别（淘天-一面-2 Q3）

**IS 的本质**：用采样分布 q 的样本估计目标分布 p 的期望，$\mathbb E_p[f] = \mathbb E_q[\frac{p}{q}f]$。除了配 clip 限制更新幅度：

1. **off-policy 修正**：行为策略（采样）≠ 目标策略（评估/更新），是 off-policy RL（Q-learning 的 importance-weighted variant、off-policy actor-critic）的基础；
2. **样本复用/经验回放**：replay buffer 里旧策略的样本重加权后继续用（PPO 的 epoch 复用、A2C 的 V-trace 截断 IS）；
3. **分布对齐**：拒绝采样、预训练/后训练数据分布修正（DPO 的隐式 IS 项、off-policy preference learning）、评测偏差修正；
4. **方差缩减**：control variates 设计中 IS 权重做基线。

**与 KL 约束的区别**：clip-IS 是**逐样本、零阶**的——限制每个动作的概率比（局部、一阶截断，梯度可归零但整体分布可能仍偏）；KL 是**分布级、软约束**——约束整个策略分布的偏离（二阶距离感知，能捕捉 clip 看不见的尾部漂移），实现上有 reward shaping（PPO-penalty、自适应 λ）、loss 正则（GRPO 的 k3）与硬投影（TRPO 的信任域）三种挂法。实践：LLM RL 用 clip + 小系数 KL（防 reference 漂移），比纯 KL penalty 稳定且便宜。

### Q4. 马尔可夫性质的形式化定义（淘天-一面-2 Q4）

状态 $s_t$ 具有马尔可夫性 ⟺ 对任意未来事件 A：

$$P(s_{t+1}\in A \mid s_t, a_t,\ s_{t-1:t-1},\ a_{0:t-1}) = P(s_{t+1}\in A \mid s_t, a_t)$$

即**给定当前状态与动作，未来与历史条件独立**（"未来只依赖现在"）。推论：策略梯度/贝尔曼方程/PPO 的 ratio 只依赖 $(s,a)$ 都以此为基础。非马尔可夫过程可通过**状态增广**（把 $(s_t, a_{t-1})$ 当新状态）恢复马尔可夫性——LLM RL 中 prompt+已生成前缀就是状态，是"增广到马尔可夫"的典型。示例代码 `grpo.py::markov_property_example`。

### Q5. 从早期策略梯度到 GRPO：哪些保留、哪些舍弃（淘天-一面-2 Q5）

演进脉络（`grpo.py::POLICY_GRAD_EVOLUTION` 表格，代码可直接引用）：

| 算法 | 保留/引入 | 舍弃/痛点 |
|---|---|---|
| REINFORCE | 策略梯度定理 $\nabla J = \mathbb E[\nabla\log\pi\cdot G_t]$ | MC 回报方差极大 |
| +baseline | 减任意 baseline 降方差（不引入偏差） | baseline 手工设计 |
| Actor-Critic | 学习 $V_\phi$ 做 baseline，TD/优势估计 | 引入 critic：偏差、双网络不稳 |
| GAE(λ) | λ 回报在 bias/variance 间平滑 | 依赖 critic 质量 |
| TRPO | KL 信任域保证单调改进 | 二阶优化（共轭梯度）实现重 |
| **PPO** | **clip 一阶近似信任域 + IS 样本复用**（保留至今） | KL 软化，critic 仍在 |
| **GRPO** | **组均值 baseline 去 critic；KL(k3) 从 reward 挪进 loss** | critic 网络与 reward shaping |

**保留主线**：策略梯度 + IS 比率 + 优势估计 + 信任域思想（clip）。**舍弃主线**：二阶优化（TRPO）、手工 baseline（→critic→又→组均值，绕回蒙特卡洛但靠大模型的大 G 与可验证奖励保方差可控）。可延伸 2025 后续：DAPO（clip-higher 放宽熵、动态采样丢全对/全错组）、Dr.GRPO（去 std 归一化纠长度偏差）、GAE 回归（过程奖励场景）。

## 二、训练工程与经典 ML 理论

### Q6. RL 场景下 MoE 模型的优化经验（AI-Infra-1 Q9）

详见《GEMM 与算子优化》Q10（同题族）。要点：rollout 与训练负载混合（推理引擎的 EP + 训练框架的 EP 权重同步）、路由随策略漂移导致负载不均（EPLB 动态复制热专家）、两跳 all-to-all 与计算重叠（DeepEP hook）、推理-训练的容量因子不一致问题。阿里追问方向：rollout 集群与 trainer 的权重更新频率（异步 RL 的 staleness）、vLLM sleep/wake 机制让权重常驻显存复用。

### Q7. RL 中 reward 引导路由偏差的问题与应对（AI-Infra-1 Q12）

现象：RL 优化的是端到端回报，MoE router 也在被优化范围内——策略可能发现"把 token 集中路由到少数 reward 高关联专家"能在短期提升回报（类似 reward hacking 的结构性利用），导致专家塌缩、长期能力退化。

应对：①**冻结 router**（RL 阶段不更新 gate 参数，最常用）；②aux loss / noaux-tc 继续生效在 RL loss 里（负载约束不因 reward 退场）；③路由 dropout/噪声正则，阻止策略依赖特定专家路径；④监测指标：路由熵、专家利用率基尼系数随 RL step 的漂移，超阈值早停回滚；⑤reward 侧审查：排除"奖励与路由捷径相关"的 reward 设计（如长度奖励可被特定专家利用）。若已经发生：回滚 checkpoint + 冻结 router 重训恢复。

### Q8. 大模型的完整训练流程（一面-2 Q8）

1. **预训练（PT）**：数万亿 token 自回归下一个词预测（CE loss），BF16 + 混合并行（TP/PP/DP/EP/SP），数据：去重/清洗/配比/课程（详见 Q9）；产物：base model。
2. **继续预训练（CPT，可选）**：领域数据（代码/多模态/长上下文）继续训练；长上下文阶段：扩 RoPE base + 长短混合数据。
3. **监督微调（SFT）**：指令-回答对，10万-百万级，chat template，loss 只算回答部分（`solutions/python/src/answers/torch_impl/sft_loss.py` 可运行）；多轮与多任务混合，产物：instruct model。
4. **偏好优化**：RLHF（reward model + PPO/GRPO）或 DPO（离线偏好对），对齐有帮助性/安全性。
5. **可验证奖励 RL（RLVR，当前主线）**：数学/代码用单测与答案判定做 outcome reward，GRPO 类算法，显著提升推理能力（R1 路线）。
6. **评估与安全**：benchmark + 红队 + 业务 case，全流程配合数据回流迭代。

每阶段都可插入：数据工程、分布式策略调整、评估门禁。面试展开自己最熟的一段（如 SFT loss mask、GRPO 细节见 Q1-Q5）。

### Q9. 预训练数据清洗的常用方法（一面-1 Q5）

按 pipeline：①**去重**：精确去重（hash）+ 近似去重（MinHash/LSH、SimHash，文档级与子串级）；②**质量过滤**：启发式规则（长度/符号比/停用词比例）、轻量分类器打分（fastText/BERT 质量分）、LLM 打分（强模型给弱数据分级）；③**语言/领域识别**：fastText lid + 配比控制（数据课程）；④**毒性/安全过滤**：关键词 + 分类器 + PII 脱敏（正则+NER）；⑤**去偏/去重人格信息**；⑥**格式修复**：HTML→markdown、PDF 解析质量分级；⑦**分词级统计**：unigram entropy 过滤低信息页。面试要点：讲**配比与课程**（代码/多语言/推理数据的配比是预训练质量的关键变量）与"清洗是性价比最高的环节"。

### Q10. 多轮对话场景下超长上下文的训练方案（实习-2 Q1）

并行策略部分详见《分布式训练》Q11（超长序列并行设计）。训练方案层：

1. **序列并行**：Ring Attention / DeepSpeed Ulysses / USP（UL+TP 组合），把超长序列切到多卡；
2. **注意力结构**：训练期滑动窗口/full 混合课程、NSA/DSA 稀疏训练（DeepSeek-V3.1+ 路线）、YaRN 外推（扩 RoPE base 至 10×+ 再短数据微调）；

4. **系统配套**：激活重算与 ZeRO 组合、context parallel + PP + EP 的三维并行排布、长度分桶 batch（长短混合降浪费）；
5. **多轮特有**：对话状态跨样本拼接（user/assistant 交替的完整上下文训练）、prefix 复用（系统前缀的样本 packing）。

### Q11. MoE 与多模态模型训练还有哪些可优化方向？（实习-1 Q2）

**MoE**：负载均衡目标进化（aux loss → noaux-tc → drop-free batch-wise 约束）、专家数/粒度/共享配比的 scaling law 细化、upcycling 初始化、EP 通信压缩（FP8 dispatch）、路由稳定性（top-k 平滑/噪声退火）、MoE 下的 muon/optimizer 调参、推理部署的专家预取与批感知路由。

**多模态**：视觉编码器与 LLM 的学习率解耦/阶段冻结、token 压缩（pixel shuffle/PruMerge/任意分辨率 patch 合并）、多模态数据课程（图文对→交错文档→任务数据）、高分辨率与视频的 3D 位置编码一致性、模态间损失冲突（梯度手术/PCGrad）、统一 embedding 空间（Qwen2-VL 的 MLP projector vs 交叉注意力之争）、RL 阶段多模态可验证奖励（图表题可判分）。

### Q12. 预训练与强化学习训练在工程上还有哪些值得优化的环节？（实习-1 Q3）

预训练：数据吞吐（dataloader 异步预取/即时 tokenization、样本 packing）、稳定性（loss spike 的检测-回滚-跳批、BF16 溢出监控、梯度范数裁剪自适应）、MFU（通信-计算重叠、EP/TP 组合调优、FP8 GEMM、kernel 融合）、checkpoint 高频低损（分层并行保存、秒级恢复）、弹性训练（节点故障的 rank 重排与断点续训）。

RL 训练（当前瓶颈最多）：①rollout 引擎与 trainer 的**权重同步**（NCCL broadcast vs RDMA 直传、sleep/wake 显存复用）；②**异步 staleness**（rollout 用旧策略的偏差 vs 吞吐收益）；③**生成效率**（投机解码用于 rollout、动态 batch、vLLM/sglang 与训练框架的同进程共存）；④**奖励计算**（沙箱执行代码单测的并行与安全、reward model 批量推理）；⑤**资源编排**（actor/critic/ref/reward 四模型共存的显存排布、PD 式分离的 RL 集群）；⑥轨迹数据管线（组采样 G 路的聚合、失败样本过滤）。

### Q13. Transformer 相比 RNN 的核心优势？Transformer 有 Scaling Law 吗？（校招-一面 Q1）

**优势**：①**训练并行**：注意力全序列一次计算，RNN 必须沿时间步递归（训练无法并行，GPU 利用率低）；②**长程依赖**：任意两 token 路径长度 O(1)，RNN 是 O(n)（梯度链长导致消失/遗忘）；③**表征**：全局感受野 + 多头多视角。代价：推理自回归无法并行（RNN 推理 O(1) 状态反而在 decode 有优势）、计算 O(S²)。

**Scaling Law**：有，且 Transformer 正是 Scaling Law 的验证载体（Kaplan 2020）：$L(N) \propto N^{-\alpha}$，参数/数据/算力幂律关系；Chinchilla（2022）修正为"给定算力，参数与数据应等比增长"（~20 token/参数）。RNN/LSTM 也有但曲线劣于 Transformer（同算力 loss 更高），这是架构胜出的本质证据。推理模型时代的新 scaling 维度：RL 计算的 test-time compute scaling（o1/R1 路线）。

### Q14. 算力受限下如何蒸馏出 3B 小模型？（云-实习-二面-2 Q5 开放题）

1. **教师**：用 API 大模型（黑盒）或开源大模型（白盒，可用 logits）；
2. **数据（比算法更重要）**：大规模指令 + CoT 推理链合成（教师生成多路解 + 筛选正确）、领域任务语料增强、难度分层课程；算力受限时数据精选（几十万高质量 > 数百万低质）；
3. **蒸馏方法**：
   - 黑盒（sequence-level）：SFT on 教师输出（含 CoT），最便宜；
   - 白盒（logit-level）：KL(teacher‖student) on token 分布（温度 T 平滑），小模型学"相对概率"信息量大于 one-hot；
   - **on-policy（GKD）**：学生自己生成、教师给分布/修正，缓解 exposure bias，算力允许时效果最好；
4. **先 SFT 后 RL**：SFT 蒸馏打底 + 少量 RLVR（可验证任务）刷新，同算力下显著优于纯蒸馏；
5. **省算力工程**：LoRA 微调而非全参、蒸馏 loss 只在关键层/关键 token 上算（重要性加权）、bf16 + 梯度检查点、教师输出缓存复用；
6. **评测**：与教师的能力对齐率、小模型基线（无蒸馏 SFT）增益、部署成本收益。

### Q15. 交叉熵损失的定义与在分类中的作用；GAN 与 CVAE 的区别（云-二面 Q1、实习-一二面 二面 Q2/Q4）

**交叉熵**：$H(p, q) = -\sum_i p_i \log q_i$。分类中 $p$ 为 one-hot 真实标签、$q$ 为 softmax 输出 → $L = -\log q_y$（正确类概率负对数）。作用：①最小化 CE = 最大化似然（MLE 推导，`svm.py` 旁注的 LR 推导同源，见 Q16）；②配合 softmax 梯度 $q - y$ 形式极简；③与 KL 的关系 $H(p,q) = H(p) + D_{KL}(p\|q)$（p 固定时等价于最小化 KL）；④加权 CE 处理类不平衡、label smoothing 正则。对比 MSE 用于分类的问题：梯度消失（softmax 饱和区）+ 惩罚过强（要求 logit 完全一致而非相对排序）。

**GAN vs CVAE**：都是隐变量生成模型 $z \to x$，训练准则不同：

| | GAN | CVAE |
|---|---|---|
| 目标 | 对抗 minmax：G 骗过 D | 变分下界 ELBO = 重构项 + KL(q(z\|x,c)\|\|p(z)) |
| 似然 | 隐式（无显式密度） | 显式下界 |
| 样本 | 锐利、真实感强 | 偏模糊 |
| 训练 | 不稳定（mode collapse、纳什均衡难） | 稳定（就是个回归+正则） |
| 条件生成 | c 进 G/D | c 进 encoder/decoder（C=条件） |
| 推断 | 采样即生成 | 需近似后验 q(z\|x)（再构造阶段） |

一句话：GAN 用判别信号换真实感、牺牲稳定性；VAE 用概率下界换稳定、牺牲锐度——扩散模型后来同时拿了两者（ ELBO + 渐进去噪）。GRPO 时代的联系：GAN 的判别器思想在 RL 的 reward model 里复活。

### Q16. Logistic 回归公式、原理与损失推导（云-二面 Q2、云-实习-二面-2 Q2）

模型：$p(y\!=\!1|x) = \sigma(w^\top x + b) = \frac{1}{1+e^{-(w^\top x+b)}}$，线性决策边界（$\sigma$ 单调不减）。

损失（BCE）从 MLE 推导：样本独立，似然 $L = \prod p_i^{y_i}(1-p_i)^{1-y_i}$，负对数：

$$\mathcal L = -\sum [y_i \log p_i + (1-y_i)\log(1-p_i)]$$

梯度：$\frac{\partial \mathcal L}{\partial w} = \sum (p_i - y_i)x_i$（sigmoid 导数 $\sigma(1-\sigma)$ 恰好消掉分式的分母平方，与线性回归同为"误差 × 输入"形式）。性质：凸（Hessian = $X^T\Lambda X$ 半正定）、概率输出可校准、多类推广 = softmax 回归（即 CE）。与 SVM 对比（衔接 Q18）：LR 损失光滑（logistic loss = smooth hinge）、概率输出；SVM 最大间隔、只依赖边界样本。

### Q17. 时间序列：ML 筛特征 + 规则建模（云-二面 Q5、云-实习-二面-2 Q4）

开放题，标准 pipeline：

1. **特征工程**：lag 特征、滑窗统计（均值/标准差/分位数）、差分与季节分解（STL）、日历特征（星期/节假日/时段）、外部变量、目标编码（类别→历史均值）；
2. **ML 筛特征**：GBDT（XGBoost/LightGBM）训练后看 gain/importance + SHAP 值排序；L1 稀疏选择；null importance（shuffle 目标后重训，过滤伪特征）；稳定性：滚动窗口多次训练取交集；
3. **规则建模**：在筛选出的强特征上构造业务规则（阈值/分位触发/环比同比条件），或"ML 预测 + 规则修正"（预测值 clip 到物理约束区间、节假日强制覆盖）；
4. **验证**：**时序切分**（train/valid/test 按时间，绝不 shuffle）、滚动 backtest（多起点）、指标按业务（MAPE/召回/误报率）；防泄漏（target encoding 用滞后窗口）。

价值点回答：规则层保证可解释与可控（金融/运维场景必需），ML 层负责泛化与交互项。

## 三、经典 ML 编程题

### Q18. 手写 SVM 核心实现（实习-一二面 二面 Q6）★

核心 = **hinge loss + 次梯度**。primal 问题 $\min \frac12\|w\|^2 + C\sum\max(0, 1-y_i(w^\top x_i+b))$，hinge 在 margin=1 处不可导 → 次梯度：违界样本（$y f(x)<1$）贡献 $\pm x_i$：

```python
# answers/alibaba/svm.py（节选，Pegasos 风格：采样次梯度 + 1/(λt) 学习率）
eta = 1.0 / (lam * t)
margins = y * (X @ w + b)
violate = margins < 1.0
w *= 1.0 - eta * lam                       # 正则项衰减
w += eta * (y[violate, None] * X[violate]).mean(axis=0)  # 违界样本次梯度
```

要点：①hinge 的次梯度只由**边界内样本**（支持向量的前驱）激活；②Pegasos 的 $\eta_t = 1/(\lambda t)$ 有理论收敛率；③对偶视角（QP/SMO/核技巧）与 primal 次梯度等价，面试口述对偶：$\max_\alpha \sum\alpha_i - \frac12\sum\alpha_i\alpha_j y_iy_j x_i^\top x_j$，$\alpha_i>0$ 的样本即支持向量，核函数替换内积。验证：线性可分数据 30 epoch 后训练精度 100%、hinge → 0（`test_svm_minibatch_separable`）。

### Q19. 手写 Transformer 核心结构（实习-一二面 二面 Q7）

内嵌最小实现（约 60 行可运行，MHA 细节见《Attention 与 KV Cache》Q5 的 `mha.py`，此处给整体组装）：

```python
import torch, torch.nn as nn, torch.nn.functional as F

class Block(nn.Module):
    def __init__(self, d, h, ffn_mult=4):
        super().__init__()
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.qkv = nn.Linear(d, 3 * d)
        self.proj = nn.Linear(d, d)                      # Pre-LN 结构（GPT 系）
        self.fc1, self.fc2 = nn.Linear(d, ffn_mult * d), nn.Linear(ffn_mult * d, d)
        self.h = h

    def forward(self, x):                                 # x: [B, S, D]
        h = self.h
        q, k, v = self.qkv(self.ln1(x)).chunk(3, -1)      # 各 [B,S,D]
        q, k, v = (t.view(*t.shape[:2], h, -1).transpose(1, 2) for t in (q, k, v))
        att = F.scaled_dot_product_attention(q, k, v, is_causal=True)  # FA 内建
        x = x + self.proj(att.transpose(1, 2).flatten(-2))
        return x + self.fc2(F.gelu(self.fc1(self.ln2(x))))  # SwiGLU 变体口头说明即可

class MiniTransformer(nn.Module):
    def __init__(self, vocab, d=256, n_layers=4):
        super().__init__()
        self.tok = nn.Embedding(vocab, d)
        self.pos = nn.Embedding(1024, d)                 # 可换 RoPE（口头加分）
        self.blocks = nn.ModuleList(Block(d, h=8) for _ in range(n_layers))
        self.ln_f, self.head = nn.LayerNorm(d), nn.Linear(d, vocab, bias=False)
    def forward(self, ids):
        x = self.tok(ids) + self.pos(torch.arange(ids.shape[1], device=ids.device))
        for b in self.blocks:
            x = b(x)
        return self.head(self.ln_f(x))                   # [B,S,vocab] → CE loss
```

追问清单：Pre-LN vs Post-LN（梯度稳定性）、RoPE 实现要点（《Attention 与 KV Cache》Q8）、GQA 改造（Q5）、 causal mask 位置、weight tying（head 与 tok embedding 共享）、训练 loss 只算答案段。

## 四、推荐系统（校招-一面 Q5-Q7/Q10）

### Q20. 生成式推荐的基本思路（校招-一面 Q5）

把推荐从"多路召回 + 排序打分"重构为**序列生成**：用户历史（item 序列）作为输入，模型自回归地"生成"下一个 item。两种技术路线：

1. **生成式检索（Generative Retrieval，TIGER/SID 路线）**：item 用语义 ID（Q21）表示，seq2seq 模型从历史 SIDs 直接生成目标 item 的 SID token 序列，beam search 出多个候选——召回与排序融合在生成里；
2. **LLM 化排序/推荐（HSTU/GR 路线）**：Meta 生成式推荐（HSTU 架构），把推荐当**因果语言建模**——用户行为流（item+时长等 token 化）训练一个生成式模型，一次前向并行出所有候选位置的概率（替换传统 DNN 多阶段）；规模上第一次让推荐模型吃满 Scaling Law（HSTU 论文：同算力效率超基线 2-3×）。

价值：端到端统一、scaling 性质好、冷启动友好（语义 ID 泛化）；代价：推理成本（生成式解码）、工业管线重构大。

### Q21. SID（Semantic ID）的训练流程（校招-一面 Q6）

三步（TIGER 流程）：

1. **内容语义编码**：用文本编码器（BERT 类）对 item 的标题/描述/属性编码 → 内容 embedding；
2. **RQ-VAE 量化为 SID**：残差向量量化——第一层 codebook 量化粗粒度（大类），残差给第二层（子类），3-4 层得到一个层级 token 序列（如 [37, 152, 8]）= item 的语义 ID；同层 codebook 联合训练（重建损失 + codebook loss）；语义相近的 item 共享前缀 → 天然的语义树；
3. **seq2seq 训练**：encoder 输入 = 用户历史的 SID 序列，decoder 自回归生成下一个 item 的 SID（cross-entropy，词表 = codebook 大小）；推理 beam search 生成 top-k SIDs → 前缀匹配/精确匹配映射回 item。

细节追问：RQ-VAE 的 codebook 失效（EMA 更新/重置死码）、SID 冲突处理、与新 item 的零样本（内容编码即可分配 SID → 冷启动）。

### Q22. TIGER 为何不用 Decoder-Only？（校招-一面 Q7）

①**范式来源**：TIGER 的定位是 generative retrieval（源自 DSI，文档检索的 seq2seq 索引生成），历史、目标天然是"条件 → 生成"两端，T5 式 encoder-decoder 结构最自然；②**编码能力**：encoder 对用户历史做**双向注意力**，历史是"被检索的条件"（无生成顺序约束），双向编码的表征效率高于因果；③**解耦生成**：decoder 只需生成目标 SID（很短，3-4 token），生成词表是 codebook（小），不需要 decoder 的长上下文能力，decoder-only 的统一输入输出优势用不上；④**实践补充**：后续工作（LC-Rec、IDGen-rec 等）证明 decoder-only（LLM 直接生成）也可行且利于统一多任务——回答时给出"不是不能，而是当时范式选择 + 双向编码收益；decoder-only 化是后续演进方向"更有层次。

### Q23. 新闻推荐的正负样本如何确定？（校招-一面 Q10）

1. **正样本**：曝光后点击（展示广告/信息流标准）；更深的行为加权——阅读时长/完播/分享可作为多目标或加权；
2. **负样本**：**曝光未点击**（全局排序的标准负例，但含 FN——内容好但没被点）；
3. **核心问题与处理**：①**样本选择偏差**（SVB）：线上只对曝光样本打分，未曝光 item 无标签 → 修复：随机流量/随机小流量曝光采样、ESMM（用 pCTR×pCVR 建模到转化）；②**位置偏差**：位置作为特征只在训练用、线上预估置 0（或 shrinkage）；③**易难负样本**：召回用 batch 内随机/热门 item 做易负例 + 挖掘 hard negative（同 session 未点的相似 item），排序用曝光未点；④**新闻特有**：时效性（新鲜度特征与时间衰减）、标题党（用时长/完播纠正点击）、多任务（点击+时长 MOE/MMoE）。

### Q25. 二叉搜索树迭代器：从暴力到最优的多解法（淘天-一面-2 Q8）★

要求"多种解法"，按复杂度阶梯给（基础栈版在《算法题》min_stack.py，本批次补三解法对比 `answers/alibaba/bst_iterator.py`）：

1. **暴力拍平**：构造时全量中序存数组，next O(1)、空间 O(n)——树只访问前几个元素时全建是浪费；
2. **受控中序 + 显式栈（标准最优）**：构造只压"根到最左"路径 O(h)；next 弹栈顶、把右子树左脊柱接上——n 次 next 每节点进出栈一次，**均摊 O(1)**，空间 O(h)；
3. **Morris 线索化（空间最优）**：临时把中序前驱 right 指回当前节点做回边，遍历后拆除——**O(1) 额外空间**、均摊 O(1)，代价是遍历中改树结构（只读场景并发不安全）。

均摊分析是隐藏考点：解法 2 单次 next 最坏 O(h)（左脊柱深），但整轮 n 次 total O(n)。三解法对拍 + Morris 恢复树结构验证：`test_bst_three_iterators_agree` / `test_bst_morris_restores_tree_structure`。
