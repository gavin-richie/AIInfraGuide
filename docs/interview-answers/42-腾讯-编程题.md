## Q4. 滑动窗口中位数（大根堆+小根堆实现）（实习-一二面 编程 13）★

> LeetCode 480：每滑动一格输出窗口中位数。**面试官要求用双堆**。

**双堆 + 延迟删除**，O(n log k)：

- 大根堆 `low` 存较小一半（Python 用负数模拟），小根堆 `high` 存较大一半，不变式 `len(low) = len(high)` 或 `= len(high)+1`，则 `−low[0]`（或两堆顶均值）即中位数；
- 入堆按与 `−low[0]` 比较路由，再平衡；
- **难点是删除过期元素**：堆不支持任意删 → 记 `delayed` 计数，元素逻辑删除、留在堆里；堆顶命中延迟标记时才真正弹出（prune）；用**有效长度** `low_size/high_size` 做平衡判断，而不是 `len()`；
- 正确性关键：堆顶（含脏元素）≥ 本堆所有有效元素，且任一脏元素 ≤ 对面堆的全部有效元素，因此用它做路由比较仍是安全的。

## Q5. 无序数组元素插入有序数组并保持有序，分析复杂度（实习-一二面 编程 8）

> 给定一个有序数组和一个无序数组，把无序数组的元素全部插入有序数组，保持有序。

两种做法、两个复杂度档位（设有序数组长 n、无序数组长 m）：

1. **逐个二分插入**：每个元素二分找位置 O(log n) + `list.insert`/memmove 挪后缀 O(n) → 总 **O(m·n)**；优点是流式（来一个插一个，无序数组不需要先到齐）；
2. **先排序再归并**：无序数组排序 O(m log m) + 双指针归并 O(n+m) → 总 **O(m log m + n)**，m 大时远优于逐插；这就是"合并两个有序数组"（LeetCode 88）套一层排序。

结论句：**离线批量用归并，在线流式用二分插入**；追问 m=1 的退化——二分插入单次 O(n) 不可避免（数组连续存储的代价，链表反之查找贵）。

```bash
pytest tests/test_tencent.py -v -k insert
```

代码：`answers/tencent/sorted_array_insert.py`（`insert_one_binary` / `insert_all_one_by_one` / `insert_all_via_merge`）。

## Q6. 口述算法：大数据场景下的经典处理问题（实习-一二面 编程 9）

开放题，答题给"方法论 + 一个完整例子"：

- **通用武器库**：哈希分桶（hash(key)%N 落盘/落机，把"放不下"变"分着放"）、Top-K 小根堆（k 大内存只留 k 个）、位图/布隆过滤器（判重/存在性，1bit 或 1.2bit/元素）、外部排序（磁盘归并，败者树优化）、分治 + 多路归并、Count-Min Sketch（近似计数）、抽样估计；
- **示范例**（100GB URL 文件，1GB 内存，找频次 Top 10）：① 逐行 `hash(url) % 1000` 写入 1000 个小文件（同 URL 必进同桶，每桶约 100MB）；② 逐桶读入 HashMap 计数 + 维护大小 10 的小根堆，得到每桶 Top10；③ 1000×10 个候选归并出全局 Top10；
- **判重例**：2.5 亿整数（int32）判重——位图 2^32 bit = 512MB 直接标 1；内存更小用两趟（高低 16 位分桶）或布隆过滤器（允许误判）；
- **中位数例**：100 亿数取中位数——按高位分桶统计各桶数量 → 定位中位数所在桶 → 桶内继续分桶（二分思想逐层逼近）。

## Q9. 实现基于内存的文件系统（字典树变体）（TEG 一面 编程 27）★

> 在内存中实现一个简易文件系统：目录树 + 文件读写。考点是把**路径字符串映射成树**（Trie 变体：每层节点 = 路径组件）。

设计：

- **节点**：`children: dict[str, Node]`（Trie 的 next 指针表）、`is_file`、`content`（文件内容，目录为空）；根节点 = `/`；
- **路径解析**：`path.split('/')` 去空段（容忍 `//`、尾斜杠），沿 children 下行——O(深度 × 组件平均长度)；
- **操作语义**（对齐 LeetCode 1166/588 与 Linux 直觉）：`mkdir(-p)` 支持递归建目录、已存在报错；`touch/write/read` 要求父目录存在且是目录；`ls` 目录返回**字典序**子项（`sorted(children)`），文件返回自身名；`rm` 非空目录默认拒绝、`recursive=True` 递归删；`mv` 换父（改两个 children 引用，O(1) 移动子树）；`du` 汇总子树内容长度；
- 边界用例：`mkdir /a/b` 父不存在、`write` 到目录、`rm` 非空目录、`mv` 到自身子目录（应拒绝，防环）。

```bash
pytest tests/test_tencent.py -v -k fs
```

代码：`answers/tencent/in_memory_fs.py`（`InMemoryFS`，含上述全部边界测试）。
