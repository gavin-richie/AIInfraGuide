## Q1. Batch Normalization：计算、作用、训练/推理差异（面-1 DL1）

**计算**（对 mini-batch 的每个通道 c）：$\hat{x} = \frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}$，$y = \gamma \hat{x} + \beta$（γ/β 可学）。

**作用**：平滑损失面（降低 internal covariate shift / 按更现代的解释是重参数化使损失更 Lipschitz）、允许更大 lr、正则化效果、缓解饱和激活。

**训练/推理差异**：训练用 batch 统计 μ_B/σ_B 且维护 running mean/var（动量滑动平均）；推理用 running 统计量（batch 无关、确定性）——`model.eval()` 切换。这就是 BN 训练不能用 batch=1、部署要融合（conv+BN 折叠，见《GEMM 与算子优化》Q13）的原因。**BN vs LN vs RMSNorm**：BN 沿通道按 batch 统计（CV/大 batch），LN 按样本内全特征统计（序列模型），RMSNorm 去均值只除 RMS（少一次统计、更快、Llama 系）；**位置**：BN/LN/RMSNorm 在残差分支前（Pre-LN 更稳）。

## Q2. Depthwise / Pointwise 卷积（面-1 DL2）

- **Depthwise**：每通道独立卷积（groups=C，K×K），FLOPs = $HWC K^2$，无跨通道交互；
- **Pointwise**：1×1 卷积做通道混合/升维降维，FLOPs = $HW C_{in} C_{out}$；
- 组合（MobileNet 块）：DW 空间滤波 + PW 通道投影，把标准卷积 $K^2 C_{in} C_{out}$ 拆成 $K^2 C_{in} + C_{in} C_{out}$（约 1/K²~1/9 计算量）。

## Q3. MobileNet v1/v2/v3、GhostNet、SE（面-1 DL3）

- **v1**：DW+PW 堆叠（上题），全深度可分离；
- **v2**：**倒残差块**（1×1 升维 → DW → 1×1 降维）+ **线性瓶颈**（降维后不加 ReLU，防低维信息被 ReLU 摧毁），shortcut 连接存在于窄→窄的层；
- **v3**：NAS 搜块结构 + **h-swish**（swish 硬件近似）+ SE 模块插入 + 修改 tail 结构；
- **SE**（Squeeze-Excitation）：GAP → FC 降维 → ReLU → FC 升维 → sigmoid，得到每通道权重逐通道相乘（通道注意力），代价极小；
- **GhostNet**：观察到特征图存在冗余 → 一部分通道正常卷积，其余用**廉价线性变换（如 3×3 DW）**生成 "ghost" 通道，省 ~50% 计算。

## Q4. YOLO v1/v2/v3 与 SSD 对比（面-1 DL4）

- **v1**：单网络回归 7×7×(B×5+C)，端到端，快但小目标差（grid 粗、一个 cell 只一类）；
- **v2**：anchor boxes（kmeans 聚类先验）、BN、高分辨率微调、多尺度训练、passthrough 细粒度特征；
- **v3**：**三个尺度头**（FPN 结构，13/26/52）+ 更好的 backbone（Darknet-53，残差）+ 每尺度 3 anchor、logistic 回归代替 softmax（多标签）；
- **SSD**：多尺度特征图直接预测（VGG backbone + 逐层预测头）、default box + 难例挖掘（负样本 3:1），无 FNP 自顶向下融合；vs YOLOv3：SSD 检出层更多、小目标好些，但 YOLO 一次卷积特征复用更彻底、更快。

## Q5. 全局池化的位置（面-1 DL5）

通常放**网络末端、分类头之前**替代 Flatten+FC：把 (H,W,C) → (1,1,C)，输出尺寸与输入解耦（支持任意分辨率）、参数量归零（GoogLeNet/ResNet）；早期也有中间 GAP 生成空间注意力图的用法（SE 前身思想）。

## Q6. 模型蒸馏原理与流程（面-1 DL6、综合-1 基础 6）

**流程**：teacher（大/带强能力）对数据输出软标签（带温度 T 的 softmax：$p_i = \frac{e^{z_i/T}}{\sum e^{z_j/T}}$，T>1 放大类间暗知识）→ student 同时拟合硬标签（CE）与软标签（KL）→ $L = \alpha T^2 KL(p_t \| p_s) + (1-\alpha) CE$。

**变体**：特征蒸馏（中间层回归/attention 转移，FitNets/KD）、关系蒸馏（样本间关系矩阵）、白盒/黑盒（API-only）。

**预训练阶段蒸馏**（综合-1 基础 6）："大模型知识蒸馏是否适合预训练阶段"——可以但作用有限：预训练目标是学通用表征而非类别判别，软标签的"暗知识"收益小；蒸馏信号更适合（数据分布相对收敛的）后训练/SFT 阶段；预训练阶段的类似技术是"浅层模型 warm-start 大模型"（层生长）或模型合并。算力受限 3B 蒸馏（阿里云真题）也是 post-train 蒸馏路线。

## Q8. Dropout 训练/推理差异（面-1 DL8）

训练以概率 p 随机置零并**按 1/(1-p) 放大**（inverted dropout，训练期做掉缩放，推理不动）；推理直接前向（期望不变）。BN 与 Dropout 同用时注意顺序（先 BN 后 Dropout 或用更稳的变体）。Transformer 常用 dropout 在 attention weights/FFN/残差处。

## Q9. 反卷积与空洞卷积（面-1 DL9）

- **反卷积（转置卷积）**：卷积的梯度形式——input/output 交换，上采样（插入 0 或分数 stride）；checkerboard 伪影问题 → 常用 upsample+conv 替代；
- **空洞卷积（dilated）**：kernel 采样点间隔 r（感受野 $K+(K-1)(r-1)$ 不增参数/计算），用于密集预测（DeepLab 的 ASPP 多空洞率并联）；gridding 问题（非网格采样/混合 dilation 缓解）。

## Q10. GIoU 损失（面-1 DL10）

IoU 对不相交框梯度为 0 → GIoU = IoU - $\frac{|C \setminus (A\cup B)|}{|C|}$（C 为最小包围框），不相交时仍有梯度（拉近方向），取值 [-1,1]。演进：DIoU（+中心距/长宽比惩罚）、CIoU（+aspect ratio 一致性）。

## Q11. Softmax 公式与用于分类的原因（面-1 DL11）

$$\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}},\quad \text{稳定版}: \frac{e^{z_i - \max z}}{\sum e^{z_j - \max z}}$$

原因：输出非负且和为 1（合法概率分布）、与 CE 损失联立得到梯度 $p - y$（形式极简）、单调可微、指数放大类间差异。数值稳定实现（减 max）见 `solutions/cuda/src/softmax.cu` 与 online_softmax.py 的溢出演示（naive 版 logits=1000 直接 inf/nan，稳定版无恙——测试 `test_softmax_overflow_demo`）。

## Q14. 优化器家族（补充高频：字节-豆包、太初）

- SGD+momentum：$v = \mu v + g$，泛化好、调参敏感；
- Adam：一阶/二阶动量自适应 $m/(\sqrt v+\epsilon)$，lr 均摊；bias correction；
- AdamW：解耦 weight decay（Adam 的 L2 与自适应冲突）；
- Muon：动量矩阵做 Newton-Schulz 正交化（谱归一化更新方向），大 batch 预训练吞吐/稳定兼得（见《分布式训练》Q7 混用问题）；
- 学习率调度：warmup（初始大梯度防震荡）+ cosine/线性衰减。

## Q15. LoRA：原理、初始化、秩 r、推理部署（综合-1 PyTorch 编程 1、MiniMax、百度-二面-2）

**公式**：冻结 $W_0$，旁路低秩增量 $y = W_0 x + \frac{\alpha}{r} B(Ax)$，只训 $A\in\mathbb{R}^{r\times d}$、$B\in\mathbb{R}^{d_{out}\times r}$。可训练参数从 $d \cdot d_{out}$ 降到 $r(d+d_{out})$（r=8 时约 1%~0.1%）。

**低秩为何有效**（百度-二面-2）：微调时权重更新量 ΔW 呈低秩谱结构（任务引入的"自由度"远小于参数维度），低秩旁路足以表达；A/B 初始化——**A 高斯随机、B 全零**，保证起点 ΔW=0 不破坏预训练分布（若都随机则初始注入扰动且梯度方差翻倍；若都为零则 A 梯度恒为零学不动——死锁）。

**秩 r 的影响**：r 过小欠拟合（容量不足，loss 降不动）；r 过大过拟合小数据 + 显存/延迟回升（旁路 kernel 变大）；经验：简单任务/大数据 r=8-16，复杂指令/领域迁移 r=32-64，一般加在 q/v 投影收益最高。

**推理部署**：可 **merge**（$W' = W_0 + \frac{\alpha}{r}BA$ 原地合并，零额外延迟）——所以"LoRA 推理是否需要 Adapter"答：单适配器直接 merge 等价于原 Linear；多适配器热切换时保留旁路（延迟增加一个小 GEMM）。
