## 链表（linked_list.py）

| 题 | 思路 | 复杂度 |
|---|---|---|
| 反转链表 | 三指针迭代 `cur.next, prev, cur = prev, cur, cur.next` | O(n)/O(1) |
| 合并两个有序链表 | 哨兵 + 双指针归并 | O(n+m) |
| 合并 K 个升序链表 | 小根堆存 (val, idx, node)，pop 头再压 next | O(N log K) |
| 链表判环 / 环入口 | 快慢指针；相遇后一头回到起点同速走，再遇即入口（数学：a = c + (n-1)L） | O(n)/O(1) |
| 相交链表 | 双指针交换走对方头部，等长后相遇（或 none） | O(n+m)/O(1) |
| K 个一组翻转 | 数够 k 个再局部反转，不足保持原序 | O(n)/O(1) |
| 删除重复元素 II | 哨兵 + 成组跳过重复段 | O(n) |
| 两数相加 | 模拟进位，注意最后进位 | O(max(m,n)) |
| 删除倒数第 N | 快慢指针间隔 n | 一趟 |
| 复制随机指针链表 | 三步法：交错复制 → 复制 random → 拆分 | O(n)/O(1) |
| 有序链表转 BST | 快慢指针找中点递归 | O(n log n) |
| 链表冒泡 | 只换 val，n-1 轮相邻比较 | O(n²) |

## LRU / 栈（lru_cache.py、min_stack.py）

- **LRU**（综合-1 算法 3）：哈希 + 双向链表 O(1)，Python 双实现（手写链表版 + OrderedDict 版）；C++ 版见《C++ 编程题》Q1。
- **O(1) 最小栈**（字节-实习-三面）：辅助栈与主栈等长同步存"当前最小"，pop 无分支。
- **BST 中序迭代器**（淘天-一面-2）：显式栈模拟中序（`_push_left`），hasNext 均摊 O(1)；Morris 线索化 O(1) 空间版思路：临时把前驱的 right 指回自己，遍历后还原。
- **两队列实现栈**：入 q2 + 搬 q1 + 交换，队首即栈顶。
- **验证栈序列**：模拟入栈，栈顶匹配 popped 即弹。

## 树与图（trees.py、graphs.py）

- **层序遍历带层级**（综合-1 算法 5、百度-一面-3）：`for _ in range(len(queue))` 逐层收割。
- **右视图**：每层最后弹出的节点。
- **非递归中序**：显式栈。
- **二叉树最大路径和**（综合-2 算法 4）：递归返回单边贡献 `max(gain,0)`，全局在节点处合并左右。
- **Path Sum III**（综合-2 算法 5）：前缀和 + 哈希 + 回溯（`prefix[acc]--` 回到祖先可见域）。
- **拓扑排序**（综合-1 考点）：Kahn（入度 BFS）与 DFS 三色两版；有环返回空。
- **岛屿数量**（综合-1 算法 4）：DFS 沉岛（改 '1'→'0'），BFS/并查集同解。
- **棋盘 BFS**（字节-实习-二面）：四连通队列扩散。
- **Trie**（腾讯-TEG）：children 字典 + is_end，insert/search/startsWith。
- **MST**（字节-一面-2 最短连通路径）：Kruskal（排序边 + 并查集）与 Prim（小根堆）双实现；**Dijkstra**：惰性删除小根堆。

## 堆 / TopK（topk_heap.py）

- **第 K 大**（壁仞、阿里）：大小 k 的小根堆 O(n log k)；**quickselect** 平均 O(n) 双实现。
- **有序矩阵第 K 小**（快手-一面-2）：多路归并堆；进阶值域二分 + count≤mid。
- **K 个有序数组中位数**（MiniMax）：值域二分 count_le。
- **前 K 高频**（综合-2 算法 7、网易）：堆 key=`(-freq, word)` 同频字典序；桶排序 O(n) 版。
- **双堆中位数**（腾讯-实习-二面）：MedianFinder 大根堆存小半 + 小根堆存大半，add O(log n)；**滑动窗口中位数**：每窗 sorted 的朴素版 + 双堆延迟删除思路讲解。
- **滑动窗口最大值**（MiniMax）：单调递减双端队列存下标 O(n)。

## 双指针 / 滑窗（sliding_window.py）

- **最长连续序列**（百度-实习-一面-1）：set + 只从起点（`x-1 not in s`）数。
- **至多 K 个不同字符最长子串**（百度同上）：计数哈希收缩左界。
- **三数之和**（旷视）：排序 + 固定一数 + 双指针 + 去重。
- **最长有效括号**（阿里-控股）：栈底存最后未匹配右括号下标作哨兵。
- **行列有序矩阵查找**（美团-校招-一面）：左下角蛇形走 O(m+n)。

## DP 与数学（dp.py、math_bits.py）

- **最大子数组**：Kadane。
- **LCS**（百度-一面-2）/ **编辑距离**（虾皮）：二维 DP。
- **最长回文子串**（小米）：中心扩展（奇偶两种中心）。
- **下一个排列**（综合-2 算法 3、字节-实习-三面）：从右找升序对 → 换稍大者 → 反转后缀。
- **两有序数组中位数**（综合-2 算法 2）：二分短数组分割线 O(log min(m,n))。
- **n! 尾随零**（快手-校招-一面）：`n/5 + n/25 + ...`。
- **环上 N 节点走 S 步回原点**（字节-校招-1）：DP `dp[s][v] = dp[s-1][v±1]`，10 节点 2 步 = 2 种（矩阵快速幂可 O(log S)）。
- **两指键盘**（综合-2 算法 9）：dp[i] = 因数分解最少按键。
- **字符串相乘**（百度-校招-二面）：先乘加进 res 数组再统一进位。
- **接雨水**（阿里-校招-一面）：双指针维护左右最大。
- **01/完全背包**（蔚来-二面）：容量倒序 vs 正序的区别（物品可否重复）。
- **K 段等长线段覆盖全部点求最短长度**（综合-2 算法 6）：**二分答案 + 贪心判定**（新线段左端贴住最左未覆盖点）。
- **K-Coverage Intervals**（综合-1 算法 7）：扫描线/差分，统计 coverage ≥ k 的长度。
- **会议室 II**（区间族）：最小堆存结束时间。
- **旋转拼接字符串第 N 位**（综合-2 算法 8）：长度翻倍 → 递归降维到前半（详见 math_bits.py 的 `nth_char_rotated_concat`，与暴力展开对拍 99 例通过——注意不是简单取模周期！）。
- **汉明重量 / 二进制第一个 1**（综合-1 算法 6）：`n & (n-1)` 消最低位 1；`x & (-x)` 取最低位。
- **快速幂**（综合-5 编程 7）：指数二进制迭代。
- **sqrt(x)**（字节-实习-一面-4）：整数二分 + 牛顿迭代双版。

## 排序与字符串（sorting.py）

- **快排**（综合-2 算法 1）：三路 partition 版 + 原地随机化双指针版；最坏 O(n²) 的触发与随机化避免。
- **堆排 / 归并 / 插入**：三个标准实现对照。
- **无库函数大写转小写并排序**（腾讯-TEG-三面）：手写 tolower（`c+32`）+ 计数排序 O(n+k)。
- **回文判断**（三星）：双指针。

## torch 语义题（broadcasting.py，综合-1 基础 9、综合-5 Q5）

- **repeat vs expand**：expand 是视图（广播维 stride=0、不拷贝、只扩 size-1 维）；repeat 真实 tile 拷贝。测试用 `stride()` 和 `storage().nbytes()` 验证（expand 32B vs repeat 128B）。
- **view vs contiguous**：view 要求连续且形状兼容；transpose 后 view 报错，需 `contiguous()`（拷贝成行连续）或 `reshape`（内部自动处理）。这正是 MHA 合并多头时 `transpose(1,2).contiguous().view(...)` 的原因。
