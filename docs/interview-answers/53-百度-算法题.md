## Q1. 最长公共子序列 LCS（一2 Q6，LeetCode 1143）

**DP**：$f(i,j)$ = s1 前 i 与 s2 前 j 的 LCS 长度；末字符相等则 $f(i,j)=f(i{-}1,j{-}1)+1$，否则 $\max(f(i{-}1,j), f(i,j{-}1))$。时空 $O(mn)$，滚动数组可压到 $O(\min(m,n))$（要还原序列则保留整表回溯）。与"最长公共子串"（连续，相等时才转移，否则清零）对比是高频追问。

**已有实现**：`algorithms/dp.py::longest_common_subsequence`（含回溯构造），测试 `test_algorithms.py`。

## Q2. 二叉树层序遍历并记录节点层级（一3 Q11，LeetCode 102 变体）

BFS，两种记录层级的方式：

```python
def level_order_with_levels(root):
    """返回 [(val, level)]，level 从 0 计 —— 两种写法二选一。"""
    if not root:
        return []
    out, queue = [], deque([(root, 0)])          # 写法1: 队列带层号
    while queue:
        node, lv = queue.popleft()
        out.append((node.val, lv))
        for child in (node.left, node.right):
            if child:
                queue.append((child, lv + 1))
    return out
```

写法 2（哨兵/双循环）：每轮 `for _ in range(len(queue))` 处理当前整层——不需要在队列里存层号，且天然按层分组（`level_order` 返回 `list[list[int]]` 的标准形态）。追问点：DFS 版（递归带 depth，按 depth 追加到桶）、每层最右节点=右视图（Q4）、锯齿形（层号奇偶决定反转）。

**实现**：`baidu/algorithms.py::level_order_with_levels`（带层号版）+ `algorithms/trees.py::level_order`（分层版），测试 `test_baidu.py::test_level_order_with_levels`。

## Q3. 合并 K 个有序链表（实1 Q6，LeetCode 23）

三解法：

1. **小根堆**：K 个头节点入堆，每次弹出全局最小、后继入堆——$O(N\log K)$（N 总节点数），最常考；
2. **两两归并**（分治）：`merge(lists, l, r)` 中点拆分递归合并，同样 $O(N\log K)$，递归深度 $O(\log K)$；顺序两两合并退化为 $O(NK)$；
3. **全收集排序**：$O(N\log N)$ 空间换简单，面试保底方案。

**已有实现**：`algorithms/linked_list.py::merge_k_lists`（堆法，配 `merge_two_lists` 哑节点归并），测试 `test_algorithms.py`。

## Q5. 用栈实现队列（实2 Q23，LeetCode 232）

双栈 + 惰性倒腾：`in` 栈只管 push；`pop/peek` 时若 `out` 空，把 `in` 全部倒入 `out`（**只有倒空时才倒**，元素每经过一次搬运后不会被二次搬运）——均摊 $O(1)$。

```python
class MyQueue:
    def __init__(self):
        self.in_stack, self.out_stack = [], []

    def push(self, x: int) -> None:
        self.in_stack.append(x)

    def _shift(self) -> None:
        if not self.out_stack:                    # 关键: out 空才倒, 保证均摊 O(1)
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())

    def pop(self) -> int:
        self._shift()
        return self.out_stack.pop()

    def peek(self) -> int:
        self._shift()
        return self.out_stack[-1]

    def empty(self) -> bool:
        return not self.in_stack and not self.out_stack
```

**实现**：`baidu/algorithms.py::MyQueue`，测试 `test_baidu.py::test_my_queue`（含均摊复杂度说明与交错操作对拍 `list` 行为）。反问题"队列实现栈"见 `algorithms/min_stack.py::TwoQueuesStack`。

## Q8. 二叉树的镜像翻转（校一2 Q6，LeetCode 226）

递归交换左右子树（后序回溯时交换亦可），或 BFS 队列每节点交换子节点入队：

```python
def invert_tree(root):
    if root:
        root.left, root.right = invert_tree(root.right), invert_tree(root.left)
    return root
```

$O(n)$ 时间、$O(h)$ 递归栈。追问：迭代版（显式栈/队列防深树爆栈）、判对称二叉树（翻转思想的应用：左子树与右子树互为镜像）。

## Q9. 字符串相乘（校二1 Q6，LeetCode 43）

大数乘法竖式：长度 m、n 的数乘积最长 m+n；**先把每一位乘积累加到结果数组第 `i+j+1`` 位**，再统一处理进位（延迟进位比边乘边进位好写好证）：

```python
def multiply(num1: str, num2: str) -> str:
    if num1 == "0" or num2 == "0":
        return "0"
    m, n = len(num1), len(num2)
    res = [0] * (m + n)
    for i in range(m - 1, -1, -1):
        for j in range(n - 1, -1, -1):
            cur = int(num1[i]) * int(num2[j]) + res[i + j + 1]      # 本位乘积 + 已积累
            res[i + j + 1] = cur % 10                                 # 个位落 i+j+1
            res[i + j] += cur // 10                                   # 进位落 i+j
    s = "".join(map(str, res)).lstrip("0")
    return s
```

$O(mn)$。位索引公式 `i+j+1` 是唯一需要现场推导的点（两数相乘，第 i 位与第 j 位贡献到结果的第 i+j+1 位）。追问：加法竖式（两字符串相加，同套路从末位进位）、不允许转 int 的幂运算快速幂。

**实现**：`baidu/algorithms.py::multiply`，测试 `test_baidu.py::test_multiply_strings`（对拍 `str(int(a)*int(b))`，含大数 999...9 边界）。
