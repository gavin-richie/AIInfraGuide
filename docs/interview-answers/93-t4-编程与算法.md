### Q4. 四维张量 Concat：描述每个维度拼接的处理方式（元戎-一面-2 1）

设输入 `A: (N,C,H,Wa)`、`B: (N,C,H,Wb)`，输出 `(N,C,H,Wa+Wb)`（dim 之外三维必须一致）：

- **dim=3（最内维 W）**：拼接发生在**行内**——每行 (n,c,h) 变成 `[A 行 | B 行]` 两段连续拷贝。线程按输出元素划分，`w < Wa` 取 A 的同 w，否则取 B 的 `w - Wa`。访存：两侧读、写全部连续，**合并访存最好**，是标准实现；
- **dim=2（H）**：拼接发生在**行间**——输出第 h 行整行来自 A（h < Ha）或 B（h - Ha）。退化为按行的 2D memcpy（每行长度 W，源行地址 = 输入行首 + 偏移），没有行内交错；
- **dim=1（C）**：粒度更粗——每个 (n,h) 上拼接的是 `C*H*W` 的**连续大条带**（通道 c 的平面是整块），直接按条带 memcpy，最接近一维拷贝，效率最高；
- **dim=0（N）**：整个张量按序追加，输出 = `[A 全部 | B 全部]`，两条 cudaMemcpyAsync 即可（无索引计算）。

规律：**拼接维越靠外，数据移动越接近大块连续拷贝；越靠内（dim=3），越要"行内交错"但依然可每行两段连续**。优化共性：多输入先算 `offsets[]` 前缀和；dim<3 时避免逐元素索引，用块拷贝（`cudaMemcpy2DAsync`/kernel 内按行循环）。

### Q5. 使用 CUDA 编写四维张量的 Concat Kernel，不同维度分别实现（元戎-一面-2 2）

**通用 kernel（任意 dim，逐元素索引推导）**——把输出线性下标反解四维坐标、定位输入、再折回输入线性下标：

```cuda
// ins: K 个输入指针; offs: [K+1] 拼接维前缀和; dims: 输出四维尺寸; dim: 拼接维
__global__ void concat4d_generic(const float* const* ins, float* out,
                                 const int* offs, const int* dims,
                                 int K, int dim, long total) {
    long i = blockIdx.x * (long)blockDim.x + threadIdx.x;
    if (i >= total) return;
    // 1) 输出线性下标 -> 坐标 (行优先连续布局)
    int coord[4], t = (int)i;
    for (int d = 3; d >= 0; --d) { coord[d] = t % dims[d]; t /= dims[d]; }
    // 2) 二分/线性定位输入 k (offs 单调, K 小线性即可)
    int k = 0;
    while (k + 1 < K && coord[dim] >= offs[k + 1]) ++k;
    // 3) 源坐标 -> 输入线性下标 (仅 dim 维尺寸不同)
    int src = 0, s;
    for (int d = 0; d < 4; ++d) {
        s = (d == dim) ? coord[d] - offs[k] : coord[d];
        int dim_size = (d == dim) ? (offs[k + 1] - offs[k]) : dims[d];
        src = src * dim_size + s;              // 逐步折叠 (row-major)
    }
    out[i] = ins[k][src];
}
// launch: total = N*C*H*Wsum, 256 线程, grid = ceil(total/256)
```

工程化：`solutions/cuda/src/concat4d.cu`（通用版 + 最后一维特化版），ctest `test_concat4d` 覆盖拼 C 维/W 维与边界。

**dim=3 特化版**（最快路径，行内两段拷贝，无坐标反解）：

```cuda
__global__ void concat4d_last(const float* a, const float* b, float* out,
                              int Wa, int Wb, int rows) {   // rows = N*C*H
    long i = blockIdx.x * (long)blockDim.x + threadIdx.x;
    long total = (long)rows * (Wa + Wb);
    if (i >= total) return;
    long row = i / (Wa + Wb), w = i % (Wa + Wb);
    bool fromA = w < Wa;
    const float* src = fromA ? a : b;
    out[i] = src[row * (fromA ? Wa : Wb) + (fromA ? w : w - Wa)];
}
```

dim=0 直接 `cudaMemcpyAsync(out, A, NA*...)` 两条拷贝；dim=1/2 用 `cudaMemcpy2DAsync`（dpitch=输出 stride、spitch=输入 stride）或 kernel 按行循环。

### Q6. CUDA 实现 uint8 数组中查找第 K 大的值（小鹏-实习 3）

值域 256 → **256 桶直方图 + 从高到低扫描**，O(n + 256)，无比较、无分支，天然适合 GPU：

```cuda
// kernel1: 全局直方图 (smem 私有化, 同 solutions/cuda/src/histogram_scan.cu)
__global__ void histogram256(const uint8_t* data, long n, unsigned* hist) {
    __shared__ unsigned local[256];
    int tid = threadIdx.x;
    for (int b = tid; b < 256; b += blockDim.x) local[b] = 0;
    __syncthreads();
    for (long i = blockIdx.x * (long)blockDim.x + tid; i < n; i += (long)gridDim.x * blockDim.x)
        atomicAdd(&local[data[i]], 1u);
    __syncthreads();
    for (int b = tid; b < 256; b += blockDim.x) atomicAdd(&hist[b], local[b]);
}
// kernel2: 单 block(256 线程) 对反转后的直方图做包含性前缀和, 边界判定输出答案
__global__ void kth_from_hist(const unsigned* hist, unsigned K, uint8_t* out) {
    __shared__ unsigned cum[256];
    int tid = threadIdx.x;
    cum[tid] = hist[255 - tid];                   // 反转: 下标 0 对应值 255
    __syncthreads();
    for (int off = 1; off < 256; off <<= 1) {     // Hillis-Steele 包含性 scan
        unsigned v = (tid >= off) ? cum[tid] + cum[tid - off] : cum[tid];
        __syncthreads();
        cum[tid] = v;
        __syncthreads();
    }
    // cum[i] = #{x >= 255-i} 关于 i 单调不减;
    // 第 K 大 = 最大的值 v 使 #{x>=v} >= K = 255 - (最小满足 cum[i]>=K 的 i)
    bool prev_small = (tid == 0) || (cum[tid - 1] < K);
    if (prev_small && cum[tid] >= K) out[0] = (uint8_t)(255 - tid);
}
```

### Q11. 用 C++ 实现 NMS + IoU（蔚来-一二三面 二面 11）

已有完整实现可引用：**C++ 版** `solutions/cpp/src/nms.cpp`（`solutions/cpp/include/answers/nms.hpp`，ctest 对拍通过）；**PyTorch 版** `solutions/python/src/answers/torch_impl/nms.py`（`nms_torch` 按步版 + `nms_vectorized` 向量化版）。流程与 IoU 公式、复杂度 O(n²)、改进方案（Soft-NMS 等）见[10 篇 Q2](./10-cpp编程题.md) 与[11 篇 Q12](./11-深度学习与训练.md)。核心五分钟版：

```cpp
double iou(const Box& a, const Box& b) {                    // xyxy
    double iw = std::max(0.0, std::min(a.x2, b.x2) - std::max(a.x1, b.x1));
    double ih = std::max(0.0, std::min(a.y2, b.y2) - std::max(a.y1, b.y1));
    double inter = iw * ih;
    return inter / (a.area() + b.area() - inter);
}
std::vector<int> nms(std::vector<Box> bs, double thr) {
    std::sort(bs.begin(), bs.end(),                          // 1) 分数降序
              [](auto& x, auto& y) { return x.score > y.score; });
    std::vector<int> keep;
    for (int i = 0; i < (int)bs.size(); ++i) {
        bool ok = true;
        for (int j : keep)                                    // 2) 与已保留框比 IoU
            if (iou(bs[i], bs[j]) > thr) { ok = false; break; }
        if (ok) keep.push_back(i);
    }
    return keep;                                              // 3) 返回原始下标
}
```

### Q18. 计算平面上两个任意朝向矩形的重叠面积（小鹏-一面 6）

任意朝向矩形是凸四边形，**两凸多边形交集仍是凸多边形** → Sutherland-Hodgman 裁剪 + 鞋带公式：

1. 矩形参数 (cx, cy, w, h, angle) → 四顶点（逆时针）；
2. 用 B 的四条边（半平面）逐条裁剪 A 的顶点序列：每条边输出"内侧顶点 + 跨边交点"；
3. 剩余 ≥3 个顶点即交集多边形，鞋带公式求面积；不相交返回 0。

**加速与鲁棒**：AABB 粗筛（包围盒不交直接 0）→ SAT 分离轴快判（8 条候选法向任一分离则不相交，比裁剪便宜）→ 精确面积再走裁剪。已知值对拍：两个单位正方形其一转 45°，交集正八边形面积 = 2(√2−1) ≈ 0.8284。

### Q24. 给定一个计算图，计算运行该计算图所需的最小内存（元戎-一面-1 8）

**题意转化**：DAG 上每个算子产出中间 tensor（给定大小），求某个执行过程中的峰值内存——本质是 **liveness（活跃区间）分析 + 内存复用**，与 MLIR bufferization 的 in-place 决策同源（[90 篇 Q9](./90-t4-编译器与mlir.md)）。分两问作答：

**①给定执行序求峰值（模拟法）**：按拓扑序逐步执行——分配输出（+size）；输入若无后续消费者立即释放（−size）；峰值 = 任意时刻占用最大值。求"最后消费者"：一次反向扫描记录每个 tensor 的最后使用步。

**②求最优（最小化峰值）**：执行顺序自由时是调度问题（NP-hard），面试给出：a) 下界 = 最大重叠活跃字节；b) 贪心——每步在就绪算子中选"净释放最多"（即将死亡的输入字节 − 输出字节）者；c) 小图可全排列拓扑序验证贪心质量；d) **内存池复用**：活跃区间不重叠的 tensor 共享同一块 arena（first-fit 偏移分配；等尺寸区间图 left-edge 最优，不等尺寸退化为 bin packing）。

实现与验证（模拟/贪心/全排列对拍/arena 不变量四组测试）：

```bash
cd solutions/python && pytest tests/test_t4.py -k "graph" -v
# 钻石图手算 80/100 两序对照; 贪心 == 全排列最优; 随机 DAG 贪心不劣于不释放;
# arena 偏移: 时间重叠的 tensor 地址不重叠
```

代码：`solutions/python/src/answers/t4/graph_memory.py`（`peak_memory`/`min_peak_greedy`/`min_peak_bruteforce`/`assign_arena_offsets`）。追问预备：权重/输入常驻怎么算（全程活跃，计入基线）；多 batch 流水（同一图 N 份错峰复用 → 峰值 ≈ 稳态一个 batch 的活跃集 + 溢出窗口）；与 vLLM PagedAttention 的分块思想对比（[91 篇 Q20](./91-t4-推理部署与tensorrt.md)）。
