## Q1. 合并两个有序数组（海康一面 Q6，LeetCode 88）

**题意**：nums1 长度 m+n（后 n 个为 0），nums2 长度 n，原地合并成有序。

**思路**：**逆向双指针**——从两数组有效尾部往前，每次把较大的放到 nums1 末尾空位。正向合并会覆盖 nums1 未处理前缀，逆向则写入区与读取区不冲突；nums2 先耗尽即可停（nums1 剩余本就在位）。时间 O(m+n)、空间 O(1)。

```python
# solutions/python/src/answers/t5/algorithms.py::merge_sorted_array
i, j, k = m - 1, n - 1, m + n - 1
while j >= 0:
    if i >= 0 and nums1[i] > nums2[j]:
        nums1[k] = nums1[i]; i -= 1
    else:
        nums1[k] = nums2[j]; j -= 1
    k -= 1
```

追问备答：链表版合并（哨兵+双指针，见 [12 算法题](./12-算法题.md) 链表节）；合并 K 个（小根堆 O(N log K)）。

## Q2. 手写 Multi-Head Attention，Masked 矩阵在哪一步引入？（联想 Q8）

**实现位置**：`solutions/python/src/answers/attention/mha.py::MultiHeadAttention`（与 `F.scaled_dot_product_attention` 对拍，`pytest tests/test_attention.py -k mha`），完整推导见 [04 Attention 与 KV Cache](./04-attention与kvcache.md)。

**手写骨架**（面试白板版）：

```python
q = self.wq(x).view(B, S, H, D).transpose(1, 2)   # (B,H,S,D) 同理 k, v
attn = (q @ k.transpose(-2, -1)) / math.sqrt(D)    # ① 先算 logits
if mask is not None:
    attn = attn.masked_fill(mask == 0, float("-inf"))  # ② mask 在 softmax 之前引入
attn = attn.softmax(dim=-1)                        # ③ -inf 经 softmax 变 0 权重
out = (attn @ v).transpose(1, 2).reshape(B, S, H * D)
return self.wo(out)
```

**Mask 引入位置（考点）**：在 **QK^T 点积之后、softmax 之前**——把不可见位置的 logits 填 $-\infty$，softmax 后权重为 0；若放在 softmax 之后做掩码会把概率质量留在被禁位置（分布不对）。mask 形状可广播 `(S, S)`/`(B, 1, S_q, S_kv)`；causal mask 是下三角；padding mask 用 key 侧掩 0；注意 fp16 下 `-inf` 与全掩行 NaN 问题（用大负数 -1e9 或保证每行至少一个可见位）。KV Cache 版本里 mask 还承担"只对已缓存 token 可见"的块状形式（PagedAttention 的 block mask）。

## Q3. 编辑距离（虾皮 Q8，LeetCode 72）；两个字符串之间的转换（好未来 Q4）

**题意**：只允许插入/删除/替换，求 word1 → word2 最少操作数。

**思路**：二维 DP——`dp[i][j]` = 前 i、前 j 个字符的最小编辑距离：

- 末字符相同：`dp[i][j] = dp[i-1][j-1]`；
- 不同：`dp[i][j] = 1 + min(dp[i-1][j-1]替换, dp[i-1][j]删除, dp[i][j-1]插入)`。

边界 `dp[i][0]=i`、`dp[0][j]=j`。O(mn) 时间/空间，滚动数组可 O(min(m,n)) 空间。

**代码位置**：`solutions/python/src/answers/algorithms/dp.py`（已有实现+对拍，见 [12 算法题](./12-算法题.md) DP 节，`pytest tests/test_algorithms.py -k edit`）。好未来 Q4"两个字符串之间的转换"若允许的操作集不同（如仅插入/删除 = LCS 变体，或相邻交换 = LDistance+2），先和面试官确认操作集再套同款 DP 框架——状态定义不变，转移按操作集改。

## Q4. 字符串转换整数 atoi（贝壳 Q13，LeetCode 8）

**题意**：跳过前导空格 → 可选 +/- → 连续数字 → 遇非数字截断；溢出钳到 $[-2^{31}, 2^{31}-1]$。

**易错点**：符号后必须紧跟数字（`"+-12"` → 0）；溢出判断在累加中即时做（防 Python 大整数不报错——C++ 里要先判 `num > (INT_MAX - d) / 10`）；`"  000001234"` 前导零；`"3.14"` 取 3。

```python
# solutions/python/src/answers/t5/algorithms.py::my_atoi
while i < n and s[i] == " ": i += 1            # 1. 空格
if i < n and s[i] in "+-": sign = ...; i += 1  # 2. 符号
while i < n and s[i].isdigit():                # 3. 数字 + 溢出钳制
    num = num * 10 + int(s[i])
    if sign == 1 and num > INT_MAX: return INT_MAX
    if sign == -1 and -num < INT_MIN: return INT_MIN
    i += 1
return sign * num
```

测试覆盖 10 个边界用例（`pytest tests/test_t5.py -k atoi`）。

## Q5. 二叉树根到叶路径组成的数字之和（好未来 Q5，LeetCode 129）

**思路**：DFS 传累积值 `cur = cur*10 + node.val`；到叶子返回 cur，否则左右子树递归相加——不用显式拼字符串，O(n) 单趟。例 `[4,9,0,5,1]` → 495+491+40 = 1026。迭代版用栈存 `(node, cur)`。实现：`t5/algorithms.py::sum_root_to_leaf`（含层序建树工具 `build_tree`）。

```python
def dfs(node, cur):
    if node is None: return 0
    cur = cur * 10 + node.val
    if not node.left and not node.right: return cur   # 叶子
    return dfs(node.left, cur) + dfs(node.right, cur)
```

## Q6. 全零方阵中绘制内切圆，用 1 填充（数坤 Q8）

**思路**：格心判定——`m[r][c] = 1 ⟺ (r-cy)² + (c-cx)² ≤ r²`，圆心 `(n-1)/2`、半径 `n/2`；O(n²) 一趟。大矩阵下填充比例收敛到 π/4（验证实现正确性的解析法）。变体追问：画圆环（内外半径）、抗锯齿（按面积覆盖率给 0-1 灰度，盒滤波/超采样）。

```python
# solutions/python/src/answers/t5/algorithms.py::draw_inscribed_circle
cx = cy = (n - 1) / 2.0
radius = n / 2.0
return [[1 if (r-cy)**2 + (c-cx)**2 <= radius**2 else 0 for c in range(n)] for r in range(n)]
```

测试断言：圆心=1、四角=0、n=301 时覆盖率 ≈ π/4（误差 <1%）。

## Q7. 判断字符串除前两个数字外，后续数字是否均由前两个相加组成（上海AI Q7）

**题意**：累加序列（Fibonacci 式）——"112358"（1,1,2,3,5,8）true、"1023" false。

**思路**：枚举前两个数的切分点 `(i, j)`（各 O(n²) 组合）→ 模拟逐项验证 `next == x + y` 且是 rest 的前缀。剪枝：前导零非法（"0" 单独合法）；第一个数超过 n/2 长度可停（剩下的装不下第二、三个数）；大数直接 int（Python 无溢出）。LC 306 Additive Number 同款。

```python
# solutions/python/src/answers/t5/algorithms.py::is_additive_string
for i in range(1, n):
    for j in range(i + 1, n):
        a, b = s[:i], s[i:j]                    # 前两个候选
        if leading_zero(a) or leading_zero(b): continue
        rest, x, y = s[j:], int(a), int(b)
        while rest:
            z = str(x + y)
            if not rest.startswith(z): break
            rest = rest[len(z):]; x, y = y, x + y
        else:
            if j < n: return True               # 至少存在第三个数
return False
```

边界："12"（无第三个数）false、"000"（0,0,0）true、"101"（1,0,1）true——见测试。

## Q8. 树形动态规划（智源一 Q4）

**代表题**：树的最大带权独立集（LC337 打家劫舍 III / "没有上司的舞会"）——相邻父子不能同时选，最大化权值和。

**思路**：树上后序 DFS，每个节点返回二元状态 `(skip, take)`：

- `skip = max(左.skip, 左.take) + max(右.skip, 右.take)`（该点不选，孩子随意）；
- `take = node.val + 左.skip + 右.skip`（选了它，孩子必不选）。

答案 `max(dfs(root))`，O(n) 一次遍历、O(h) 栈空间。实现：`t5/algorithms.py::house_robber_iii`，测试与**指数暴力枚举**（所有选/不选组合检查独立性）对拍 30 组随机树。

树形 DP 通用框架（答追问）：状态定义在"子树 + 边界约束"上、后序合并子树信息（最大值/和/计数/方案数）、入口在根（或换根 DP 两遍扫处理"以每个点为根"）。其他常考：树的最长路径（直径）、最小点覆盖、树上背包（依赖背包 O(n·V)）。

## Q11. 用 CUDA 实现 100 万个浮点数的求和（小厂实4 Q10）

**已有实现与实测**：`solutions/cuda/src/reduce.cu`（详见 [02 CUDA 编程题](./02-cuda-编程题.md) 归约题：RTX 3090 实测 atomic 1.962ms → 优化版 0.016ms，**124×**；`ctest --test-dir build` 6 测试全绿）。答法阶梯：

1. **思路**（两阶段）：grid 切块 → 每 block 内树归约（smem）→ 每 block 一个部分和 → 第二个 kernel/最后 block 把部分和累加；
2. **关键优化**：每线程先串行累加多元素（grid-stride，减线程数）、warp shuffle 完成最后 32 路归约（免 smem/同步）、消除分支分歧（步长式归约）、smem bank conflict 规避、float4 向量化读、`__ldg` 只读缓存；避免全局 atomicAdd（串行化）；
3. **数值精度追问**：百万 float 顺序累加误差大——分块求和（每块内先和再归约）误差 O(√n) 级改善；Kahan 求和或 fp64 累加器兜底；
4. 量级判断：1M×4B=4MB 数据，3090 带宽 936GB/s → 理论 ~4.5µs，实测 16µs 已接近 launch 开销地板——顺势聊 CUDA Graph。

## Q13. 概念速答：递归的优缺点；DFS 与 BFS 解方程组；图算法知识（小厂实面 Q6/Q7/Q8）

- **递归**：优点——分治问题（树/图/回溯）表达自然、代码短；缺点——函数调用栈开销（每层保存现场，O(depth) 栈空间、深递归栈溢出）、重复子问题（无记忆化指数级，如 naive Fibonacci）、缓存不友好、异常传播难定位。改写：尾递归优化（编译器未必支持）、显式栈迭代化、记忆化/DP 化、对于树的问题用 Morris 遍历 O(1) 空间。
- **DFS/BFS 求解"方程组"场景**（原题语境是把状态转移建成图搜索）：把每个未知量当节点、依赖/转移关系当边——**DFS** 适合依赖链深的（记忆化搜索天然自顶向下、递归求闭式，如 `f(i)=f(i-1)+f(i-2)` 的记忆化）、可回溯/判环（拓扑序求解）；**BFS** 适合求**最少步数/最短依赖链**（等价最短路，逐层扩展状态，如"从初值出发最少几步凑出目标值"）、层序天然给迭代层级。差异本质：DFS 深入+回溯（栈，空间 O(h)，找所有解/存在性），BFS 逐层（队列，空间 O(w)，最优性/最短）；方程有环（互相依赖）需 SCC/不动点迭代。
- **图算法**（答知识面）：表示（邻接表/矩阵）；遍历（DFS/BFS 及其应用：连通分量、拓扑排序、环检测）；最短路（Dijkstra 非负、Bellman-Ford 负权、Floyd 全源）；最小生成树（Kruskal/Prim）；强连通（Tarjan）；网络流（最大流/二分匹配）；并查集（连通/ Kruskal 辅助）；PageRank/社区发现（扩展面）。完整实现见 `solutions/python/src/answers/algorithms/graphs.py`（拓扑/岛屿/MST/Dijkstra/Trie，[12 算法题](./12-算法题.md) 图节）。
